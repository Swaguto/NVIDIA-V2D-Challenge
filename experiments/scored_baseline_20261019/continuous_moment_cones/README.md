# Continuous conditional moment cones

Four bounded serial CPU jobs implement a new continuous PSD separation method.
The independent checker completes its numerical certificates, then its report
writer fails on a duplicate schema keyword. That exact source/status is retained;
a separate report-only writer consumes saved evidence without repeating checks.
Private matrices, tables, solver returns and journals are not in this archive.
Production runtime/tests remain unchanged.

Ten new contracts cover unnormalized maps, signed/zero mass, exact rational
polynomial-square separation, scale-invariant planes, a full-rank measure,
strict shapes and a new tiny conic phase-I/dual control. They do not rerun the
prior controls. Eigenvectors are polynomial coefficients, never joint commands.

The declared algorithm reuses the prior starting LP return. Fixed limits are
six LP updates, 64 unique exact planes per update, seven cone audits, 20 seconds
per subproblem and 5,990 rows. Every new plane has a negative exact square
expectation and a nonnegative-square identity. All six subproblems return phase-I
zero and zero exact dual exclusion margin. The final table still has 698 failing
PSD matrices. No continuation, larger limit or tolerance sweep follows.

Independent checks verify 4,130 conditioned groups, 8,260 matrices, 41,300
principal minors, 5,254 rational square planes, all 384 selected planes,
six exact selections and six residual-corrected finite-box duals. Final unit-box
failures are zero; equality/inequality residuals are 1.553e-14/1.895e-8.
These are LP diagnostics, not changed source/trajectory acceptance tolerances.
The initial saved table is rechecked under new cone maps and is not new source
or physical evidence.

The fixed inherited source/time family remains unresolved. No pose, source truth,
common global measure, trajectory, native motor/grasp or task success qualifies.
All verified components and original source/missing/held-out evidence and gates
remain unchanged. No native position, physics, GPU/PPO or score gain occurred.
